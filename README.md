# Meridian Gate

Waitlist landing page for [Meridian](https://github.com/Edoouuard/meridian-terminal), the prompt-to-trade DeFi terminal. Standalone site, separate from the terminal itself.

**Live:** https://meridian-gate-seven.vercel.app

## Stack

Vite, React, TypeScript, Tailwind CSS v4, shadcn/ui.

## Develop

```bash
npm install
npm run dev
```

## Deploy

Connected to Vercel; pushes to `master` auto-deploy. To deploy manually:

```bash
vercel deploy --prod
```
